# Bloom · AI 마케팅 에이전트 프로토타입

Render(https://tryrender.ai/)의 광고 제작·캠페인 운영 컨셉을 참고한 독립적인 한국어 로컬 프로토타입입니다.

## 실행

이 폴더에서 `npm start` 또는 `python3 -m http.server 4173 --bind 127.0.0.1`를 실행하고 http://localhost:4173 에 접속하세요. 별도 패키지 설치는 필요하지 않습니다. Node.js는 문법 검사에만 필요합니다. macOS에서는 `실행.command`를 더블클릭할 수도 있습니다.

## 체험 순서

1. 브랜드 키트: 브랜드 이름·소개·색상·톤 저장
2. AI 스튜디오: 광고 아이디어 입력, 채널·포맷 선택, 시안 생성
3. 대화 수정: `더 짧게`, `할인 강조`, `더 따뜻하게`, `30% 할인`, 또는 `"원하는 헤드라인"` 입력
4. 스타일 선택 및 SVG 다운로드 (사진을 파일 안에 포함)
5. 캠페인 저장: 이름과 일 예산을 지정
6. 캠페인: 운영 시뮬레이션 시작·일시 정지, 예산 수정, Autopilot 광고 제안
7. 라이브러리: 저장한 시안을 다시 열어 수정

## 구현 범위

- 프레임워크와 외부 런타임 의존성 없는 HTML/CSS/JavaScript
- 반응형 데스크톱·모바일 UI, 입력 검증, 안전한 텍스트 렌더링
- 현재 브라우저의 localStorage에 브랜드·시안·캠페인 저장
- 로컬 규칙 기반 카피 구성. LLM 및 이미지·영상 생성 API 미연결
- 사진은 고정된 커피 샘플. 다른 제품도 텍스트만 변경됩니다.
- 15초 포맷은 텍스트 스토리보드. 실제 동영상·음성·음악 생성 미구현
- 대시보드 성과는 명시된 샘플. 실제 광고 계정·게시·결제·로그인 미연결
- Autopilot은 광고 테스트 제안 추가 데모. 실제 최적화·예약 작업 없음
- 브라우저 데이터를 지우면 저장 내용이 초기화됩니다. 민감한 정보를 입력하지 마세요.
- 최초 폰트 로딩에 Google Fonts 사용. 네트워크가 없어도 시스템 폰트와 로컬 사진으로 동작합니다.

## 다음 구현 단계

브랜드별 서버 저장 및 인증 → LLM 기반 광고 기획·구조화 응답 → 생성형 이미지/영상 작업 큐 → 파일 스토리지 → 광고 플랫폼 OAuth → 사용자 승인 후 광고 게시 → 실제 성과 수집 및 최적화.
API 키는 브라우저 코드에 넣지 않고 서버 환경 변수로 관리해야 합니다.

## 검증

`npm run check`로 JavaScript 문법을 검사합니다. 실행한 후 위 체험 순서로 주요 기능을 확인할 수 있습니다.
